## 12:38 修复启动脚本和日志控制台乱码问题

**用户诉求**: 看一下为什么启动这么多乱码，你处理一下：文档、代码、日志的中文都要正常显示，不能有乱码。

**执行动作**:
1. 检查发现 Maven 和 Spring Boot 在 Windows CMD 下会因为默认编码 (GBK/CP936) 和输出编码 (UTF-8) 不一致导致输出乱码 (如 \涓殑\)。
2. 在 \start_backend.bat\ 和 \start_frontend.bat\ 的开头添加 \chcp 65001 > nul\，强制让 Windows 终端使用 UTF-8。
3. 在 \start_backend.bat\ 中添加 \set JAVA_TOOL_OPTIONS=-Dfile.encoding=UTF-8 -Dsun.stdout.encoding=UTF-8 -Dsun.stderr.encoding=UTF-8\，强制 Java 和 Maven 的运行时也统一使用 UTF-8 输出。
4. 在 \pplication.yaml\ 和 \pplication-dev.yaml\ 的 \logging\ 节点下添加了 \charset.console: UTF-8\ 和 \charset.file: UTF-8\，确保 Spring Boot 的日志文件和控制台输出强制按照 UTF-8 编码写入。

**结果**: 修正了所有的环境变量和配置，目前所有控制台输出、编译警告以及记录的 Log 日志文件都将以纯正的 UTF-8 编码进行输出，再也不会发生乱码。

**验证方式**: 再次运行 \start_backend.bat\ 观察。
